# drawings — K 線畫線與跨裝置同步

## Purpose

在 K 線上畫分析線並跨裝置(手機⇄電腦)同步;畫線永遠黏著 K 棒(縮放/平移/面板調整都不跑版)。

## Requirements

### R1: 工具集
選取 / 趨勢線 / 水平線 / 垂直線 / 矩形 / 筆刷 / 文字 / 橡皮擦;樣式(顏色/線寬 1-5px);復原/重做(歷史 80 步)/刪除選取/清除全部(破壞性→二次確認)/匯出圖片/**刷新畫線**(從雲端重拉,免 F5)。

### R2: 儲存鍵與座標
畫線依 **現股代號 × 週期** 分開儲存;錨點=**(時間, 價格)** 資料座標(非像素),故換窗寬/縮放自動跟隨。

### R3: 穿透式選取模式
#### Scenario: 看盤手勢照常
- WHEN 選取模式啟用
- THEN 平移/縮放/調軸/副圖把手全部照常,**只有壓到線**才進入編輯(拖圖形或端點)
#### Scenario: 點線即選取、點空白回看盤
- WHEN 看盤模式下點擊既有圖形 → 直接進選取並選中該圖形
- WHEN 以「點線」進入的選取模式下點空白 → 一鍵回看盤(工具列進入的不受影響);Esc 一律回看盤

### R4: 本地+雲端同步(local-first)
1. 每次變更:**本地先存**(離線保底)→ 登入時整包 PUT 上雲(最後寫的贏);狀態膠囊顯示 已同步雲端/已儲存在此裝置/儲存失敗。
2. 載入:本地毫秒級先上 → 雲端背景抓到後「無感替換」;期間使用者已動手畫則不覆蓋。
#### Scenario: 資料保全鐵則(空雲端不吞本地)
- WHEN 雲端回空、本地有畫線(未登入時期畫的)
- THEN 以本地為準**反向推上雲**,絕不讓空雲端清掉本地
#### Scenario: 手動刷新
- WHEN 按工具列「刷新畫線」
- THEN 重跑載入流程(含上述保全規則),同步其他裝置變更;同步中 icon 旋轉+按鈕鎖定

### R5: 幾何監看(不跑版鐵則)
常駐 rAF 迴圈(前端)監看幾何簽名(Y range + 可視首尾根的 convertToPixel.x),任何變化(hover 縮放面板/拖邊界/圖表重排)→ 當幀重繪 overlay,畫線最多落後 1 frame。klinecharts `layout()` 是微任務,overlay 重繪也走微任務 FIFO 排其後。

## 資料來源/端點

| 動作 | 端點 |
|---|---|
| 拉雲端 | `GET /api/drawings/{現股代號}/{週期}`(JWT) |
| 推雲端 | `PUT /api/drawings/{現股代號}/{週期}`(整包覆蓋) |
| 本地 | IndexedDB/localStorage(drawingRepository) |

後端儲存=per-member(JWT sub 隔離),鍵=member×sid×period。

## Out of scope
- 多人共享畫線、畫線版本歷史、衝突合併(整包最後寫的贏)

## 已知缺口
- 未登入純本地時跨裝置自然不同步(by design);登入後首次載入即觸發反向上傳補齊
