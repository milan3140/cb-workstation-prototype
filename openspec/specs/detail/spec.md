# detail — 標的明細

## Purpose

單檔 CB 的完整決策資訊:關鍵數字、契約條款、發行公司體質、籌碼、CBAS 試算,五區塊一頁看完。

## Requirements

### R1: 五區塊
**關鍵指標**(CB收盤/現股、距轉換價(到位度)、型態訊號、熱度、未轉換、距賣回、**折/溢價**)/ **契約條款**(轉換價、到期日/到期價、擔保、強制贖回風險(觸發130%·連續30天·觸價),更多條款展開)/ **信用體檢**(綜合體質燈號)/ **籌碼**(集保庫存異動、三大法人買賣)/ **CBAS 試算**(所需權利金、槓桿倍數)。

### R2: 呈現位置(依斷點)
- 桌面(≥1280):右欄常駐,**全部展開** + 頂部區塊 tabs;點 tab 平滑捲至該區塊,捲動時 scroll-spy 反標當前 tab(近底時標最後一個)。
- 平板(840-1279):中欄「明細」按鈕開抽屜(隱藏抽屜內 K 線,避免與中欄重複)。
- 手機(≤839):列點擊開全螢幕抽屜(含 K 線)。

### R3: 策略視角
明細主角依來源策略頁調整:方向型策略(發動/熱度)以 K 線型態為主角;折價/賣回策略不賭方向,以到位度/下檔保護為主角,K 線只當參考。

## 資料來源

| 區塊 | 來源 |
|---|---|
| 關鍵指標/契約 | 自有表 `cb_master`(主檔)+ `cb_close`(收盤)+ `cb_basic`(基本資料/停轉期間) |
| 折/溢價 | 由收盤與百元平價衍生(refresh 計算) |
| 信用體檢 | 主檔欄位衍生燈號(creditLight) |
| 籌碼 | `GET /api/cb_custody.json`(`cb_custody`,24月)+ `GET /api/cb_legal.json`(`cb_legal`,逐日三大法人) |
| 除權息/借券 | `exdiv` / `borrow` |

## Out of scope
- 下單/交易連動、歷史條款版本

## 已知缺口
- 折/溢價欄位色彩曾誤用語義色,現規格=**白色**(非漲跌語義)
